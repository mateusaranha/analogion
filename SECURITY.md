# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk before a fix is available.

If GitHub's **Private vulnerability reporting** feature is enabled for this repository, use it to report security issues privately.

If that feature is not enabled, contact the repository owner through an appropriate private GitHub channel before public disclosure.

When reporting a vulnerability, include enough information to reproduce and assess it, such as:

- affected page or feature;
- reproduction steps;
- expected and actual behavior;
- browser/environment details when relevant;
- proof of concept when appropriate and safe.

## Scope

Analogion is a static client-side application hosted on GitHub Pages. It has no application backend, but security issues may still involve dependencies, browser storage, imported JSON, embedded YouTube content, or build/deployment configuration.

Please report issues affecting the repository or application code. Problems in YouTube itself should be reported to YouTube/Google through their own channels.
